# YUME Website

YUME — веб-каталог аниме. Текущая версия получает сведения о тайтлах из Shikimori, использует Cloudflare Workers для выполнения приложения и Cloudflare D1 для постоянного хранения импортированного каталога.

Текущий адрес для проверки: <https://yume-website.yumesupport833.workers.dev/>. Это рабочий адрес Cloudflare Workers, а не утверждение о будущем постоянном домене проекта.

## Технологии

- React, TypeScript и TanStack Start.
- Vite и Tailwind CSS.
- Bun для установки зависимостей и запуска команд проекта.
- Cloudflare Workers / Nitro для серверного приложения.
- Cloudflare D1 для хранения каталога; binding: `YUME_DB`.
- Shikimori GraphQL API — источник метаданных аниме.

## Что входит в текущий объём

- Главная страница, каталог и разделы популярного, новинок, анонсов и выходящих сейчас тайтлов.
- Тематические подборки.
- Поиск, фильтры, сортировка, пагинация и передача состояния каталога через URL.
- Страницы тайтлов с описанием, метаданными, похожими аниме и трейлером YouTube, если подходящий трейлер доступен.
- Интерфейс на русском и английском языках, настройки темы оформления.
- Избранное и «Мой список» с локальным сохранением в браузере.

Каталог заполняется постепенно и ограничен 1 000 тайтлами. Это текущее продуктовое ограничение: увеличение полноты каталога вынесено за пределы текущего объёма работ.

## Известные ограничения

- Полноценный плеер серий не подключён. Сейчас доступен только YouTube-трейлер, если он найден в данных Shikimori; интерфейс режима просмотра серий является заглушкой и не имитирует воспроизведение.
- Раздел «История просмотров» пока является поясняющей заглушкой и ничего не сохраняет. Его целевая логика — показывать аниме, которые пользователь начал, но ещё не досмотрел; после подключения плеера для них можно будет сохранять просмотренные серии и место остановки. Полностью просмотренные тайтлы не должны попадать в список «Продолжить просмотр».
- Регистрация, авторизация, серверные пользовательские профили и синхронизация библиотеки между устройствами не реализованы. Избранное и «Мой список» хранятся только в текущем браузере.
- Реклама и Premium не реализованы и остаются вне текущего этапа.
- Поведение зависит от доступности Shikimori. При ограничениях API каталог может загружаться постепенно, частично или временно быть недоступен.
- Некоторые старые демонстрационные структуры остаются в исходных файлах. Их наличие не следует считать доказательством работы истории просмотров, расписания серий или плеера.

Подробный перечень текущих ограничений и критерии готовности MVP ведутся в [документе готовности MVP и итогового QA](docs/mvp-readiness.md).

## Локальный запуск

Требуется установленный Bun и подходящая версия Node.js для используемых инструментов.

```bash
bun install --frozen-lockfile
bun run dev
```

## Команды проверки

Эти команды предназначены для локальной разработки. При документальном аудите шестого этапа запуск CI и повторный запуск автоматических проверок не производятся.

```bash
bun run test
bun run lint
bun run build
```

Конфигурация Cloudflare находится в `wrangler.jsonc`, а workflow проверки Worker — в `.github/workflows/cloudflare-worker.yml`. Для production-сборки используются сгенерированные Nitro/Cloudflare артефакты. Перед любым production-деплоем необходимо проверить целевую среду и актуальный адрес размещения.

## Публикация и домен

Текущая рабочая версия доступна через Cloudflare Workers по адресу выше. Прежний адрес Vercel не является актуальным адресом сайта. Постоянный хостинг и окончательный домен будут определены отдельно после завершения работ над сайтом; перед этим необходимо согласованно обновить canonical URL, sitemap и ссылку Sitemap в `robots.txt`.

**Важное состояние перед запуском:** юридические ссылки в пользовательском интерфейсе пока ведут на заглушки, а не на полноценные утверждённые тексты. Политика и остальные юридические документы — рабочие проекты; не публиковать их до заполнения данных оператора и проверки фактической инфраструктуры, журналов, сроков хранения, локализации и трансграничной передачи. Яндекс Метрика, реклама, Premium и полноценная OAuth-регистрация не считаются активными функциями только на основании упоминаний в документах.

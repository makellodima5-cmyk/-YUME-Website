# YUME Website

YUME — веб-каталог аниме с метаданными Shikimori. Проверочный адрес текущей конфигурации: <https://yume-website.yumesupport833.workers.dev/>. Это адрес Cloudflare Workers, а не постоянный домен целевого запуска.

## Текущий стек

- React, TypeScript, TanStack Start, Vite и Tailwind CSS.
- Bun для установки зависимостей и команд проекта.
- Nitro / Cloudflare Workers для серверного приложения.
- Cloudflare D1 для каталога и предусмотренных таблиц аккаунтов.
- Shikimori GraphQL API — источник метаданных.

## Текущие функции

- Главная страница, каталог, подборки и страницы тайтлов.
- Поиск, фильтры, сортировка и пагинация.
- Русский и английский интерфейс, тема оформления.
- Избранное и «Мой список» с локальным сохранением в браузере.
- Встроенный YouTube-трейлер, если ID найден в данных.
- Серверное ограничение заданных Shikimori ID для страны RU в текущем Cloudflare-варианте.

Каталог заполняется постепенно и ограничен 1 000 тайтлами.

## Ограничения и целевой запуск

- **Полноценный плеер серий не подключён.** Сейчас доступны только трейлеры. Интеграция стороннего видеопровайдера планируется позднее, после того как сайт будет показан потенциальным поставщикам и согласованы условия.
- **OAuth-код VK ID и Яндекс ID существует, но текущие кнопки выключены.** Серверный код требует настройки приложений, ключей и callback URI; он использует Cloudflare Workers/D1. Для целевого запуска на Selectel нужно адаптировать runtime и БД либо явно решить, какие Cloudflare-компоненты остаются. Дополнительно проверить текущий VK ID backend: он обращается к id.vk.com, тогда как релиз официального SDK от 12.09.2026 сообщает о переходе авторизации на vk.ru.
- **Яндекс Метрика ещё не подключена в проверенной ветке.** По целевому плану владельца она должна появиться на старте. До публикации Политики нужно установить счётчик, зафиксировать настройки и связать загрузку аналитики с выбором пользователя.
- **Управление cookie-согласием пока не реализовано.** Сейчас баннер имеет одну кнопку «Хорошо» и записывает отметку закрытия. Выбор «Принимаю» / «Отклоняю» и блокировка аналитики после отказа требуют разработки и проверки.
- **Selectel в РФ — целевой хостинг, а не завершённая миграция.** Переход требует адаптации серверного runtime, БД, OAuth и геолокации по IP.
- История просмотров остаётся заглушкой; серверный прогресс просмотра не реализован.
- Реклама и Premium не реализованы.
- Каталог зависит от доступности Shikimori.
- Текущий список территориальных ограничений — стартовый технический список, а не полный официальный реестр.

## Локальный запуск

Требуется Bun и подходящая версия Node.js.

```bash
bun install --frozen-lockfile
bun run dev
```

## Проверки

```bash
bun run test
bun run lint
bun run build
```

Успешный CI не равен подтверждённому production-деплою. Перед релизом нужно проверить целевую инфраструктуру и публичный домен.

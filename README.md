# YUME — веб-каталог аниме

YUME — проект веб-каталога аниме, который находится в разработке. Текущий функционал сосредоточен на поиске и изучении тайтлов. Полноценный просмотр серий через видеоплеер пока не реализован.

- **Текущая опубликованная версия:** https://yume-website.yumesupport833.workers.dev/
- **Рабочая ветка:** [feat/telegram-mini-app](https://github.com/makellodima5-cmyk/-YUME-Website/tree/feat/telegram-mini-app)

Адрес `workers.dev` используется как временный адрес проекта и не является постоянным собственным доменом. Публичная версия сайта может не включать все изменения из рабочей ветки до их отдельной публикации.

## Что уже реализовано

- Каталог аниме на основе метаданных Shikimori с хранением каталога в Cloudflare D1.
- Главная страница и разделы «Популярное», «Новинки», «Анонсы» и «Сейчас выходит».
- Страницы тайтлов с описанием, рейтингами и другой доступной информацией, похожими тайтлами и YouTube-трейлером, если он найден.
- Поиск, фильтры, сортировка, пагинация и сохранение состояния каталога в URL.
- Интерфейс на русском и английском языках, настройки оформления.
- «Избранное» и «Мой список» с локальным хранением в браузере.
- В рабочей ветке начата интеграция Telegram Mini App: адаптация интерфейса к Telegram WebApp, серверная проверка данных Telegram и API для синхронизации пользовательских списков. Интеграция и бот остаются в разработке и требуют настройки и проверки перед полноценным запуском.

Каталог постепенно заполняется и на текущем этапе ограничен примерно 1 000 тайтлами. Он не является исчерпывающей базой всех существующих аниме.

## Что пока не реализовано

- **Просмотр серий:** собственного видеоплеера и интеграции Kodik пока нет. Сейчас на страницах могут отображаться только YouTube-трейлеры.
- **История просмотра:** фактическое сохранение просмотренных серий и позиции воспроизведения не работает.
- **Завершённая Telegram-интеграция:** наличие кода Mini App и API не означает, что бот и все сценарии уже готовы для публичного использования.
- **Регистрация для обычного сайта:** полноценная универсальная система учётных записей и профилей для сайта не входит в текущий реализованный функционал.
- **Монетизация:** реклама и Premium не подключены. Интеграция Яндекс Метрики не считается действующей функцией.
- **Постоянный домен:** окончательный домен проекта ещё не выбран.
- **Юридические страницы:** документы в `docs/legal/` являются проектами и требуют заполнения и проверки перед публикацией.

## Технологии

- React и TypeScript.
- TanStack Start и TanStack Router.
- Vite и Tailwind CSS.
- Bun для управления зависимостями и запуска команд.
- Cloudflare Workers и Nitro для серверного приложения.
- Cloudflare D1 для хранения каталога; binding базы данных — `YUME_DB`.
- Shikimori API — источник метаданных аниме.

## Локальный запуск

Необходимы Bun и версия Node.js, совместимая с зависимостями проекта.

Установка зависимостей:

```bash
bun install --frozen-lockfile
```

Запуск сервера разработки:

```bash
bun run dev
```

## Проверки

```bash
bun run test
bun run lint
bun run build
```

## Публикация

Конфигурация Cloudflare находится в `wrangler.jsonc`. Команда публикации:

```bash
bun run deploy:cloudflare
```

Для публикации необходимы доступ к нужному аккаунту Cloudflare, настроенная база D1 и корректные параметры окружения. Перед публикацией нужно проверить целевую среду и убедиться, что необходимые секреты заданы. Изменения в рабочей ветке не следует считать опубликованными, пока это отдельно не подтверждено.

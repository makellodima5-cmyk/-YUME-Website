# Рекламные места YUME

**Статус:** каркас реализован; рекламные кампании и рекламные сети не подключены.  
**Актуальность:** 28 октября 2026 г.

## Размещение

1. Главная: между блоками «Популярное» и «Новинки». Место показывается только если на главной есть блок «Популярное».
2. Страница аниме: под секцией плеера и над блоком «Похожие аниме».

Места в каталоге и в списках аниме не добавлены. Всплывающей рекламы нет. Adsterra, другие рекламные сети и их SDK сейчас не подключены; этот каркас предназначен в первую очередь для прямых рекламодателей и партнёрских кампаний.

## Как вручную разместить рекламу

Рекламные кампании хранятся в одном файле: `src/data/advertising.ts`. Каждый слот изначально выключен (`enabled: false`), поэтому до настройки кампании он вообще не рендерится и не резервирует место на странице.

1. Подготовить материал рекламодателя. Для баннера добавить файл в `public/ads/`, например `public/ads/brand-banner.webp`. Для видео использовать браузерный видеоформат, обычно MP4, например `public/ads/brand-video.mp4`. Не добавлять в репозиторий материал без разрешения правообладателя.
2. В `ADVERTISING_SLOTS` открыть нужный слот и заполнить конфигурацию:
   - `enabled: true`;
   - `format: "image"` или `format: "video"`;
   - `asset: "/ads/brand-banner.webp"` либо `"/ads/brand-video.mp4"`;
   - `href: "https://advertiser.example/"` с реальным адресом рекламодателя;
   - `alt` с коротким описанием материала;
   - при необходимости `advertiser`, `campaignName`, `startsAt` и `endsAt`.
3. Сохранить изменения и проверить публикацию на компьютере и телефоне. Для остановки кампании достаточно вернуть `enabled: false` или задать дату окончания. В конфигурации используются ISO-даты, например `2026-11-01T00:00:00Z`.

Рекламное видео воспроизводится автоматически без звука, повторяется по кругу и не имеет пользовательских элементов управления. Отдельная ссылка ведёт на сайт рекламодателя. Автозапуск без звука нужен в том числе для совместимости с ограничениями браузеров. Для изображения весь баннер является ссылкой. Ссылки принимаются только с протоколами HTTP/HTTPS, изображения допускают локальные пути из `public` или HTTPS-адреса.

**Пример настройки изображения** (это пример формата, не активная кампания):

```ts
"home-between-popular-new-releases": {
  enabled: true,
  format: "image",
  asset: "/ads/brand-banner.webp",
  href: "https://advertiser.example/",
  alt: "Название рекламной кампании",
  advertiser: "Название рекламодателя",
  campaignName: "Осенняя кампания",
  startsAt: "2026-11-01T00:00:00Z",
  endsAt: "2026-11-30T23:59:59Z",
},
```

Не включай пример, не подставив реальные материал и адрес. Для второго места используется слот `anime-below-player`.

## Технические принципы

- Общий компонент `src/components/yume/AdvertisingSlot.tsx` используется для обеих точек.
- Идентификаторы мест стабильны: `home-between-popular-new-releases` и `anime-below-player`.
- Без активной конфигурации компонент возвращает `null`: нет пустого блока, зарезервированной высоты, внешних рекламных запросов или стороннего SDK.
- У кампании есть формат, материал, ссылка, рекламодатель, необязательный период показа и внутреннее название.
- Прямая реклама и партнёрские кампании настраиваются одинаково. Позже Adsterra можно подключить отдельным адаптером, не меняя сами точки размещения.
- Блоки маркируются как реклама. Встроенное видео не использует autoplay и не создаёт всплывающих окон.
- Проверяются протоколы ссылок и адреса материалов, даты кампании и выключенное состояние.

## Перед запуском реальной рекламы

1. Проверить права на размещаемые изображения и видео, а также правила рекламодателя/партнёрской программы.
2. Для подключения рекламной сети отдельно проверить актуальные требования к сайту и подтвердить одобрение домена. Само наличие рекламных мест не означает, что сеть приняла сайт.
3. Проверить применимые требования к маркировке рекламы, договорам и обработке персональных данных в странах, где будет показываться реклама.
4. При подключении сторонней сети оценить её SDK, cookies, рекламные идентификаторы, основание/согласие на обработку данных и обновить Политику конфиденциальности до загрузки скриптов.
5. Проверить кампанию на адаптивность, срок действия, рабочую ссылку и отсутствие показа после отключения.

Пока источник кампании не настроен и не одобрен, нельзя утверждать, что на сайте активна реклама или что Adsterra подключена.

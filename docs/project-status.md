# YUME — актуальное состояние проекта

**Дата аудита:** 22 октября 2026 г.  
**Репозиторий:** makellodima5-cmyk/-YUME-Website  
**Основная ветка:** main. Документационные изменения находятся в PR #39.

## Подтверждено кодом

- Каталог аниме и страницы тайтлов используют метаданные Shikimori; каталог заполняется постепенно и ограничен примерно 1 000 тайтлами.
- Текущая серверная архитектура — TanStack Start/React, Nitro/Cloudflare Workers и Cloudflare D1 (binding YUME_DB).
- «Избранное» и «Мой список» сохраняются локально в localStorage браузера, без серверной синхронизации.
- На странице тайтла может отображаться YouTube-трейлер через youtube-nocookie.com.
- Серверный геофильтр ограничивает заданные Shikimori ID для страны RU.
- Backend-код OAuth/регистрации VK ID и Яндекс ID существует. Схема хранит внутренний ID, провайдера и стабильный ID провайдера, дату рождения, отметку времени/версии согласия; сессии хранятся в виде хеша токена.
- Кнопки провайдеров в текущем UI явно отключены через disabled. Работающая production-авторизация не подтверждена.
- Cookie-баннер имеет одну кнопку «Хорошо» и сохраняет отметку закрытия в localStorage. Выбора аналитики и блокировки запросов при отказе нет.
- Яндекс Метрика не обнаружена в проверенной ветке.
- Полноценный плеер серий, реклама и Premium не реализованы.

## Целевой план владельца

- Перенести целевую инфраструктуру на Selectel в РФ.
- Включить VK ID и Яндекс ID для публичного запуска.
- Подключить Яндекс Метрику к запуску.
- На первом этапе предоставить каталог, метаданные и доступные трейлеры; полноценный внешний плеер серий подключить позднее, после согласования с поставщиком.
- Позже заменить cookie-баннер на «Принимаю» / «Отклоняю» с реальным управлением аналитическими запросами.

## Критические расхождения перед запуском

1. Перенос на Selectel сам по себе не активирует OAuth: нужно адаптировать Cloudflare-specific runtime и D1, настроить приложения, ключи/секреты и callback URI; UI-кнопки пока отключены.
2. Геофильтр использует Cloudflare country metadata. При прямом размещении на Selectel эти данные не гарантированы.
3. Метрику нужно фактически установить и проверить, а необязательные аналитические запросы связать с выбором пользователя.
4. Фактический домен, данные оператора, целевая услуга/БД, сроки логов и резервных копий пока не подтверждены.
5. Наличие юридических файлов в репозитории не означает, что полноценные публичные правовые страницы опубликованы на сайте.

Успешный CI не подтверждает production-деплой или готовность будущей инфраструктуры Selectel.

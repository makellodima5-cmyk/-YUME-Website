# YUME — актуальное состояние проекта

Дата: 22 октября 2026 г.  
Репозиторий: makellodima5-cmyk/-YUME-Website, ветка main.

## Подтверждённые функции
- Веб-каталог и страницы тайтлов на метаданных Shikimori.
- Постепенное заполнение Cloudflare D1 с лимитом порядка 1 000 тайтлов.
- Поиск, фильтры, сортировка, пагинация, интерфейс RU/EN.
- «Избранное» и «Мой список» в localStorage конкретного браузера.
- Встроенные YouTube-трейлеры, если подходящий ID доступен.
- Серверный фильтр заданных Shikimori ID для country code RU.

## Не описывать как текущую функцию
- Полный просмотр серий / собственный видеохостинг.
- Серверная история просмотров.
- Полноценная авторизация, облачные профили и синхронизация.
- Работающая подписка Premium или реклама.
- Подключённая Яндекс Метрика.
- Исчерпывающий список всего контента, запрещённого в России.

## Целевая инфраструктура (план, не production)
- Выбран Beget VPS в Санкт-Петербурге: 2 vCPU, 4 ГБ RAM, 40 ГБ NVMe, Ubuntu 24.04 LTS, публичный IPv4. По экрану заказа — 1 140 ₽/мес. за сервер и IPv4. Сервер ещё не создан.
- Приложение по факту аудита всё ещё ориентировано на Cloudflare Workers и D1. Требуется перенос на Node/Nitro и новый локальный адаптер БД.
- Данные текущей D1 переносить не планируется: новую БД создадим пустой, каталог заполним заново из Shikimori.
- Подробный план: [Cloudflare → Beget VPS](migration/cloudflare-to-beget-vps.md).

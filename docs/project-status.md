# YUME — актуальное состояние проекта

Дата: 22 октября 2026 г.  
Репозиторий: makellodima5-cmyk/-YUME-Website, ветка main.

## Подтверждённые функции
- По сведениям владельца, авторизация активна; точный провайдер, доступность production-потока и состав сохраняемых данных требуют сверки с конфигурацией и реальным сценарием.
- По сведениям владельца, Яндекс Метрика используется. В кодовом аудите интеграция не была обнаружена, поэтому способ подключения и настройки требуют отдельной проверки.
- Веб-каталог и страницы тайтлов на метаданных Shikimori.
- Постепенное заполнение Cloudflare D1 с лимитом порядка 1 000 тайтлов.
- Поиск, фильтры, сортировка, пагинация, интерфейс RU/EN.
- «Избранное» и «Мой список» в localStorage конкретного браузера.
- Встроенные YouTube-трейлеры, если подходящий ID доступен.
- Серверный фильтр заданных Shikimori ID для country code RU.

## Не описывать как текущую функцию
- Полный просмотр серий / собственный видеохостинг.
- Серверная история просмотров.
- Авторизация: статус «активна» сообщён владельцем, но не подтверждён в этом аудите end-to-end; детали реализации см. docs/auth-setup.md.
- Работающая подписка Premium или реклама.
- Яндекс Метрика: активность подтверждена владельцем, но ID счётчика, способ подключения, маскирование IP, Webvisor, цели и фактические запросы пока не подтверждены.
- Исчерпывающий список всего контента, запрещённого в России.

## Неизвестные сведения, не подлежащие домысливанию
- ФИО оператора, почтовый адрес, контактный email и окончательный домен.
- Фактическая инфраструктура production (владелец указал «other»); конфигурация репозитория сама по себе не доказывает весь путь данных.
- Какой OAuth-провайдер включён в production и какие поля он возвращает.
- Настройки Яндекс Метрики и наличие внешнего подключения вне репозитория.

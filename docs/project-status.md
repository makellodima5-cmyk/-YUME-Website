## Подтверждено проверенной кодовой конфигурацией (не считать состоянием будущего production)

- Текущая архитектура использует TanStack Start/React, Nitro/Cloudflare Workers и Cloudflare D1.
- Каталог использует метаданные Shikimori.
- Избранное и «Мой список» в текущем интерфейсе сохраняются в localStorage, без серверной синхронизации.
- Встроенные трейлеры могут использовать YouTube.
- Backend-код VK ID и Яндекс ID существует, но текущие UI-кнопки были отключены; работающий production OAuth не подтверждён.
- Код регистрации предусматривает запрос и хранение даты рождения. Нужно решить, оставить ли это поле для возрастной защиты и проверить фактическое основание/срок.
- Яндекс Метрика не обнаружена в проверенной ветке.
- Cookie-баннер содержит кнопку «Хорошо» и не реализует отдельный выбор согласия/отказа или блокировку аналитики.
- Геофильтр использует Cloudflare country metadata, поэтому при прямом размещении на Selectel требует адаптации, если Cloudflare не останется в цепочке запросов.
- Полноценный плеер серий, реклама и Premium не реализованы.

## Ключевые риски и задачи перед запуском

1. **Правовой статус оператора:** нужна отдельная юридическая проверка модели физического лица, не гражданина РФ, с ВНЖ, но без ИП/самозанятости/организации.
2. **Уведомление РКН:** проверить исключения по статье 22 152-ФЗ; если уведомление требуется, направить до начала обработки, а не после начала публичной работы.
3. **Адрес оператора и домен:** не определены/не оформлен; публичные документы пока нельзя завершить.
4. **Selectel:** миграция требует выбора конкретной услуги, переноса/замены Workers/D1, БД, OAuth, геофильтра и настройки логов/backups.
5. **Удаление:** пожелание владельца — удалять все данные пользователя; реализация полного удаления и поведение backups/logs пока не подтверждены.
6. **История просмотра:** заявлена как целевые аккаунтные данные, но текущая реализация в документации кода указана как незавершённая.
7. **OAuth:** необходимо включить кнопки и пройти end-to-end тесты с production callbacks. Для Яндекс OAuth владельцу без гражданства РФ официально предлагается обратиться в поддержку по вопросу проверки сервиса.
8. **Cookie / Метрика:** требуется новый баннер «Принимаю» / «Отклоняю», блокировка счётчика до согласия и проверка реальных сетевых запросов.
9. **18+:** нужна реальная возрастная защита и определённый источник рейтингов. Полная дата рождения уже встречается в текущей схеме регистрации и требует отдельного решения по минимизации.
10. **Kodik:** будущая интеграция возможна только после получения условий/разрешения и технической проверки.
11. **Юридические тексты:** наличие файлов в GitHub не означает их публикацию или правовую готовность. Финальные документы должны совпадать с фактической production-конфигурацией.

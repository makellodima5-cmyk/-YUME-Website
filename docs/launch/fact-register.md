# YUME — реестр подтверждённых фактов, целевых решений и открытых вопросов

**Редакция:** 22 октября 2026 г.  
**Статус:** рабочий реестр перед запуском. Не является юридическим заключением или подтверждением работающего production-сервиса.

Этот документ разделяет сведения по их происхождению. Решение владельца о целевой конфигурации не доказывает, что функция уже реализована в коде или включена в production.

- Оператор описан владельцем как физическое лицо, не гражданин РФ, с видом на жительство; не зарегистрирован как самозанятый, ИП или юридическое лицо.
- ФИО оператора: **Макелло Дмитрий Алексеевич**.
- Рабочий адрес для обращений: **yume.anime@mail.ru**.
- Адрес оператора для официальных документов пока неизвестен и требует отдельного решения.
- **AnimeYume.ru** — планируемый домен; ещё не куплен, DNS/HTTPS и постоянные URL не подтверждены.
- Планируется инфраструктура Selectel на территории РФ. Конкретный продукт, runtime, БД, хранилище резервных копий и роль Cloudflare не определены; текущая проверочная инфраструктура использует Cloudflare Workers и D1.
- Вход планируется через VK ID и Яндекс ID. По решению владельца из провайдеров нужен только стабильный ID для привязки аккаунта. Никнейм пользователь задаёт самостоятельно после регистрации.
- В пользовательском аккаунте планируется хранить историю просмотра и избранное. Реальная схема хранения и синхронизации ещё должна быть сверена с кодом и целевой БД.
- Яндекс Метрика планируется только для базовой статистики и должна загружаться **только после явного согласия на аналитику**.
- Владелец хочет, чтобы при удалении аккаунта удалялась вся относящаяся к аккаунту информация. Реализация удаления и поведение резервных копий/технических журналов пока не подтверждены.
- Аудитория может включать несовершеннолетних; контент с маркировкой 18+ должен быть недоступен несовершеннолетним. Механизм проверки возраста, источник возрастных меток и поведение для незалогиненных посетителей ещё нужно определить и реализовать.

- Рассматриваемый видеопровайдер — Kodik. Интеграция отложена до получения разрешения/подтверждения условий со стороны провайдера.
- Реклама планируется позднее и не относится к стартовой конфигурации.
- По ответу владельца уведомление Роскомнадзора ещё не подавалось; владелец намерен разобраться и выполнить необходимую подачу до начала публичной обработки данных.
- Сроки хранения данных, журналов и резервных копий пока не выбраны.

## 2. Подтверждено документацией репозитория / предыдущей проверкой кода

Следующие сведения относятся к проверенной кодовой конфигурации, а не автоматически к будущему production:

- Приложение использует React/TypeScript, TanStack Start/Nitro и Cloudflare Workers; для каталога используется Cloudflare D1.
- Данные каталога запрашиваются у Shikimori.
- Встроенные трейлеры могут загружаться через YouTube (youtube-nocookie.com).
- «Избранное» и «Мой список» в текущем интерфейсе сохраняются в localStorage; они не являются серверной синхронизированной библиотекой. История просмотра в документации к проверенной ветке отмечена как незавершённая/заглушка.
- Код OAuth/регистрации VK ID и Яндекс ID существует, но проверенная версия UI содержала отключённые кнопки входа. Production-авторизация не подтверждена.
- Код регистрации запрашивал дату рождения и предусматривал её сохранение в таблице аккаунта. Это отдельное поле, вводимое на стороне YUME, а не обязательно данные, полученные от VK ID/Яндекс ID.
- В проверенной ветке не обнаружена интеграция Яндекс Метрики.
- Текущий cookie-баннер имеет одну кнопку «Хорошо», сохраняет отметку закрытия в localStorage и не предоставляет выбора согласия/отказа или блокировки Метрики.
- Географический фильтр использует метаданные страны Cloudflare. При прямом переходе на Selectel эту логику нужно адаптировать или отдельно решить, останется ли доверенный proxy.
- Реклама, Premium и полноценный плеер серий в проверенной версии не реализованы.

## 3. Требуемое целевое поведение

- VK ID и Яндекс ID привязывают аккаунт по стабильному внешнему ID; не запрашивать и не сохранять лишние поля профиля.
- Яндекс Метрика включается только после выбора «Принимаю» для аналитики. При отказе счётчик и необязательные аналитические запросы не выполняются.
- Пользователь может изменить выбор позже через настройки cookie.
- Удаление аккаунта удаляет все связанные активные записи пользовательских данных: внутренний профиль, внешний ID-провайдера, никнейм, историю просмотра, избранное и активные сессии/идентификаторы, относящиеся к аккаунту. Поведение логов и резервных копий должно быть отдельно определено и согласовано с применимыми обязанностями хранения.
- Контент категории 18+ не отображается и не открывается несовершеннолетним; правила возрастной классификации и техническая проверка возраста должны реально работать до включения такой контентной выдачи.
- Стартовый сайт описывается как каталог/метаданные/трейлеры. Kodik и другие источники серий не указываются как подключённые до разрешения и интеграции.
- Публичные юридические тексты публикуются только после согласования юридически значимых сведений и фактической конфигурации.

## 4. Открытые вопросы / блокеры

### Оператор и домен
- [ ] Указать допустимый адрес оператора для Политики и уведомления Роскомнадзора.
- [ ] Юридически проверить оформление деятельности физического лица, не являющегося гражданином РФ, с ВНЖ и без статуса ИП/самозанятого/организации.
- [ ] Купить домен, настроить DNS/HTTPS и окончательные URL правовых страниц.
- [ ] Подтвердить, что yume.anime@mail.ru доступен для обращений по персональным данным и правообладателей.

### Персональные данные и инфраструктура
- [ ] Выбрать конкретный продукт Selectel, runtime, БД, места резервного копирования и журналирования.
- [ ] Решить, останется ли Cloudflare как DNS/CDN/WAF/proxy и какие данные он продолжит получать.
- [ ] Установить сроки хранения для профиля, истории просмотра, избранного, сессий, журналов и резервных копий.
- [ ] Определить фактический пользовательский путь удаления аккаунта и проверить удаление по всем хранилищам.
- [ ] Разобрать расхождение по истории просмотра: владелец ожидает её как данные аккаунта, а проверенная документация к коду указывает, что функция незавершена.
- [ ] Разобрать, зачем форма запрашивает полную дату рождения; решить, нужна ли она для возрастного фильтра или нужно другое решение с минимизацией данных.

### OAuth и провайдеры
- [ ] Проверить точные scopes, callback URI, токены и фактически сохраняемые поля VK ID/Яндекс ID.
- [ ] Проверить совместимость VK ID с актуальными endpoints.
- [ ] Яндекс указывает, что для владельца сервиса без гражданства РФ может потребоваться обращение в поддержку для верификации OAuth; проверить доступность регистрации/подтверждения именно для аккаунта владельца.
- [ ] Закончить OAuth end-to-end после переноса, а не считать миграцию хостинга достаточной для автоматического включения авторизации.

### Согласие, дети и контент
- [ ] Реализовать кнопки «Принимаю» / «Отклоняю» и реальную блокировку аналитических запросов до согласия.
- [ ] Выбрать настройки Метрики: IP-маскирование, Вебвизор, автоматические цели и недопустимые пользовательские параметры. До отдельного решения — не передавать UserID, внешний ID, никнейм, дату рождения и содержимое форм.
- [ ] Установить, будет ли дата рождения храниться для ограничения 18+ и как она удаляется вместе с аккаунтом.
- [ ] Определить правила для несовершеннолетних при регистрации и просмотра общего каталога, отдельно от доступа к 18+.
- [ ] Уточнить условия Kodik и получить разрешение до подключения видеоплеера.
- [ ] Проверить актуальные требования к возрастной маркировке и распространению материалов 18+.

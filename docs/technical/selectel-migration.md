# Переезд YUME на Selectel: технические зависимости

Статус: целевой план владельца; миграция не подтверждена как завершённая.

## Текущая архитектура по коду
- Серверные маршруты работают в контексте Cloudflare Workers/Nitro.
- Модули авторизации используют Cloudflare Workers API и binding YUME_DB (Cloudflare D1).
- Каталог хранится в D1; см. migrations/ и docs/persistent-catalog-d1.md.
- Геофильтр использует request.cf.country и запасной заголовок CF-IPCountry.
- OAuth требует YUME_AUTH_SESSION_SECRET, YUME_PUBLIC_ORIGIN, VKID_CLIENT_ID, VKID_REDIRECT_URI, YANDEX_CLIENT_ID, YANDEX_CLIENT_SECRET и YANDEX_REDIRECT_URI.
- Кнопки VK ID и Яндекс ID в UI сейчас отключены.

## Что не произойдёт автоматически при переезде
1. Выбрать конкретную услугу Selectel и способ запуска приложения в целевой среде.
2. Заменить/адаптировать Cloudflare-specific runtime и binding D1; мигрировать каталог и аккаунты в целевую БД.
3. Перенести схемы, индексы и данные, проверить целостность, backup/restore и rollback.
4. Настроить OAuth-приложения, production callback URI и секреты для нового домена.
5. Включить кнопки UI после end-to-end-проверок.
6. Адаптировать GeoIP: request.cf.country отсутствует вне Cloudflare Workers; CF-IPCountry появится только если запрос проходит через настроенный Cloudflare proxy.
7. Проверить регионы БД, бэкапов, логов, почты и все внешние потоки. Российский основной сервер не гарантирует отсутствие передачи данных за рубеж.
8. Настроить HTTPS, доступ администратора, секреты, мониторинг, сроки хранения и план отката.

## Яндекс Метрика
Метрика не найдена в проверенном коде. По плану владельца её надо включить к запуску. До публикации Политики следует подключить счётчик, зафиксировать его номер и настройки IP-маскирования, Вебвизора, UserID/целей и проверить блокировку необязательных запросов после отказа.

## Данные и правовые условия целевой инфраструктуры

Подтверждённые решения владельца:
- целевая инфраструктура должна находиться в РФ и планируется на Selectel;
- будущая аккаунтная модель включает самостоятельно заданный никнейм, историю просмотра и избранное;
- пользователь ожидает удаление всей связанной с аккаунтом информации;
- Яндекс Метрика для базовой статистики должна запускаться только после явного согласия;
- домен AnimeYume.ru пока не куплен, а адрес оператора не определён.

Неизвестные параметры, которые нельзя угадывать:
- конкретная услуга Selectel, регион и схема сети;
- runtime и замена Cloudflare Workers/Nitro, а также миграция D1;
- целевая БД и регионы хранения backup/logs;
- останется ли Cloudflare перед российским origin и какие данные сможет обрабатывать;
- сроки хранения, backup rotation и подтверждённое уничтожение аккаунтных данных;
- договорное поручение на обработку персональных данных и роли фактических поставщиков.

Выбор Selectel сам по себе не доказывает полную локализацию: до запуска нужно проверить все базы, backups, журналы, почтовый сервис и потоки к внешним API. Selectel публикует информацию о поручении на обработку персональных данных: https://selectel.ru/solutions/pdps/.

Миграция должна включать тест удаления аккаунта и всех связанных активных записей, проверку восстановления/удаления backups, а также проверку блокировки Метрики до согласия пользователя. Публичные документы обновляются только после фактической проверки.

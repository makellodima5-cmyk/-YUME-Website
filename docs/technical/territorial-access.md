# Территориальные ограничения доступа по стране IP

**Текущая реализация:** находится в main; изменения PR #38 прошли CI.  
**Целевой хостинг:** Selectel в РФ; механизм геолокации при переезде требует отдельной адаптации.

## Подтверждено кодом

- Конфигурация ограничений находится в src/data/territorial-restrictions.ts.
- Стартовый список: Shikimori ID 22319 (Tokyo Ghoul), 6880 (Deadman Wonderland), 1818 (Claymore).
- Текущий Cloudflare Worker использует request.cf.country с резервным чтением CF-IPCountry.
- Фильтр применяется к каталожной выдаче и прямому запросу тайтла.
- Для ответов с территориальным ограничением настроено предотвращение shared-cache использования.

## Ограничения

- Три ID — стартовый технический список, не полный и не заверенный перечень всех материалов, ограниченных в РФ.
- Страна определяется по IP-адресу выхода, видимому сетевой инфраструктуре; VPN учитывается по стране выходного IP, а не по гражданству или месту проживания.
- IP-геолокация может ошибаться. Поведение при неизвестной стране нужно явно выбрать.
- Для каждого ограничения необходимо хранить проверяемое основание, точный объект ограничения, дату проверки и лицо, ответственное за пересмотр.

## При переезде на Selectel

Если запрос обслуживается напрямую на Selectel, request.cf.country отсутствует, а CF-IPCountry не появляется автоматически. Требуется решить:

1. Оставить Cloudflare доверенным proxy с подходящей настройкой геозаголовков либо выбрать отдельную GeoIP-базу/службу.
2. Если Cloudflare убирается, определить лицензию GeoIP, механизм обновления базы и место её обработки.
3. Выбрать поведение при неизвестной стране и ошибке GeoIP.
4. Если используется proxy-заголовок, принимать его только от доверенного proxy и исключить клиентскую подмену.
5. После миграции протестировать прямую выдачу тайтла, а не только скрытие карточки в каталоге.

## Проверки

- [ ] Страница/API ограниченного ID корректны из RU.
- [ ] Поведение из другой страны соответствует выбранному правилу.
- [ ] Неизвестная страна обрабатывается предсказуемо.
- [ ] Источник заголовка страны доверенный.
- [ ] Переезд не выключает фильтрацию.
- [ ] Для каждого ID сохранено конкретное основание и дата проверки.

## Текущая схема

- Серверный код читает request.cf.country; предусмотрен fallback к CF-IPCountry.
- Фильтрация применяется к ответам каталога и отдельной страницы тайтла.
- Если страна нормализуется к RU, ID из RU_RESTRICTED_ANIME_IDS исключаются из ответа.
- Странозависимые ответы помечаются Cache-Control: private, no-store.
- VPN классифицируется по выходному IP, который видит Cloudflare; физическое местонахождение и гражданство не устанавливаются.
- Коды XX и T1, отсутствие или некорректный код считаются неопределёнными; в этом случае российский фильтр не применяется.

## Покрытие и пределы

Покрыты серверная выдача каталога и прямой ответ тайтла через общую Server Function. Полноценный плеер серий не подключён; при его реализации доступ к каждому видео/источнику должен контролироваться сервером или контролируемым backend. Новые endpoints и альтернативные источники должны включаться в фильтр и тесты. Геолокация IP может быть ошибочной.

## Регресс-тесты перед запуском

1. RU: ID из списка отсутствуют в каталоге и прямой выдаче.
2. NL/US: тайтл не отфильтровывается только по географии.
3. XX/T1/unknown не классифицируются как RU.
4. Обычные тайтлы доступны.
5. Странозависимый ответ не попадает в общий кэш.
6. Проверка выполняется по реальному Cloudflare request, а не только в локальном preview.

Политика конфиденциальности должна описывать обработку страны IP. Техническое ограничение не заменяет юридическую оценку контента.

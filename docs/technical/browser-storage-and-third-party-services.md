# Хранилища браузера и сторонние сервисы YUME

**Основание:** аудит репозитория main на 22 октября 2026 г. Повторить сетевой аудит фактического production URL перед запуском.

## Browser storage

| Ключ / источник | Назначение | Где хранится | Оговорка |
|---|---|---|---|
| yume-language | Язык интерфейса | localStorage | Не облачный профиль |
| yume-theme | Тема | localStorage | Не серверный аккаунт |
| yume-cookie-notice-acknowledged | Факт закрытия уведомления | localStorage | Не подтверждает согласие на необязательные технологии |
| yume-favorite-anime-v1 | ID сохранённых тайтлов | localStorage | Нет облачной синхронизации |
| yume-watchlist-anime-v1 | ID списка просмотра | localStorage | Нет облачной синхронизации |

Код содержит заготовки для прогресса просмотра, но это не следует описывать как работающую историю просмотра, пока не подключён реальный плеер и не работает соответствующий пользовательский сценарий.

## Сторонние сервисы

| Сервис | Текущая роль | Проверка до запуска |
|---|---|---|
| Cloudflare Workers / Nitro | Выполнение приложения, входящие запросы | Сторона договора, IP/access/security logs, retention, regions, условия обработки и локализация |
| Cloudflare D1 (YUME_DB) | Метаданные каталога | Размещение, резервные копии, доступы; не путать с базой пользовательских профилей |
| Shikimori GraphQL API | Источник метаданных | Условия API, атрибуция, правила изображений/описаний и сетевые потоки |
| YouTube / youtube-nocookie.com | Встроенные трейлеры | Фактические iframe-запросы и технические идентификаторы |
| Яндекс Метрика | Не обнаружена как интеграция в проверенном коде | Не указывать как активную без подключения и сетевой проверки |
| VK ID / Яндекс ID | Будущая авторизация, не подтверждена как production | OAuth credentials, redirect URI, поля, сессии, удаление профиля |
| Реклама / Premium | Не реализованы | Сначала выбрать поставщика и оформить данные, согласия и правовые требования |

## Правила

- Не записывать будущие функции как действующие.
- Не утверждать, что сайт вообще не хранит IP: инфраструктурный поставщик может хранить логи независимо от D1.
- Не называть localStorage cookie, хотя можно описывать вместе как cookie и похожие технологии.
- Не считать закрытие баннера согласием.
- Для каждого нового поставщика фиксировать юридическое лицо, роль, цели, поля, место обработки, сроки, договор и дату проверки.

# YUME — browser storage, cookie и сторонние сервисы

**Редакция:** 22 октября 2026 г.  
**Статус:** техническая спецификация целевого запуска, сверенная с ответами владельца. Текущая реализация описана отдельно и не должна путаться с планом.

## Решения владельца — целевая конфигурация

- Яндекс Метрика для базовой статистики запускается только после явного согласия на аналитику.
- Баннер должен предлагать «Принимаю» и «Отклоняю». Отказ блокирует счётчик и необязательные аналитические запросы.
- Пользователь должен иметь возможность изменить выбор позднее через доступный пункт «Настройки cookie».
- VK ID и Яндекс ID используются для привязки аккаунта по стабильному ID; никнейм пользователь придумывает сам.
- Удаление аккаунта должно удалять всю связанную активную пользовательскую информацию, включая профиль, внешний ID, никнейм, историю просмотра, избранное и активные сессии. Точное поведение backup и технических журналов должно быть определено отдельно.
- Полноценный плеер серий и рекламные технологии в стартовую модель не входят. Сейчас доступны только трейлеры.

## Текущая проверенная реализация

- В браузере используются localStorage-ключи для языка, темы, отметки закрытия cookie-уведомления, избранного и «Моего списка».
- Избранное и «Мой список» — локальное хранилище браузера, не серверная синхронизированная библиотека.
- Cookie-баннер имеет кнопку «Хорошо» и записывает факт закрытия уведомления. Он не предлагает отдельный выбор согласия/отказа и не блокирует необязательные аналитические запросы.
- Интеграция Яндекс Метрики в проверенной ветке не обнаружена.
- Встроенные трейлеры могут использовать YouTube через youtube-nocookie.com. Даже с доменом youtube-nocookie браузер обращается к инфраструктуре YouTube; эту связь нужно учитывать в проверке фактических сетевых запросов.
- Полноценный плеер серий, реклама и Premium не реализованы.

## Целевая логика согласия

1. До выбора пользователя не загружать необязательную аналитику.
2. «Принимаю» записывает выбор и разрешает запуск Метрики в утверждённой конфигурации.
3. «Отклоняю» записывает отказ и не запускает Метрику или связанные необязательные аналитические запросы.
4. Дать пользователю возможность изменить решение позже. При изменении на отказ прекратить последующую загрузку аналитики и очистить доступные приложению аналитические идентификаторы, если это технически возможно и требуется выбранной моделью.
5. Не смешивать строго необходимые механизмы с аналитикой. Само закрытие баннера или продолжение использования сайта не означает согласия.
6. Сохранять только минимально необходимые сведения о выборе: значение, версия текста/настроек и отметка времени, если это требуется для подтверждения выбора. Не устанавливать срок без решения владельца и проверки правовых требований.

## Целевая конфигурация Яндекс Метрики

Владелец планирует только базовую статистику посещаемости. Перед публикацией необходимо создать счётчик, проверить настройки и фактические запросы.

Рекомендация для стартовой конфигурации, требующая подтверждения в настройках счётчика:
- включить маскирование IP-адреса;
- отключить Вебвизор;
- не передавать UserID, VK ID, Яндекс ID, никнейм, дату рождения или содержимое форм;
- не включать автоматические цели и дополнительные функции до отдельной проверки;
- запускать счётчик только после явного согласия на аналитику.

Документация Яндекса указывает, что Метрика использует cookie и localStorage для браузерных идентификаторов. Маскирование IP — отдельная настройка счётчика, а не автоматическое свойство любого подключения.

- Cookie Метрики: https://yandex.ru/support/metrica/ru/general/cookie-usage.html
- Маскирование IP: https://yandex.ru/support/metrica/ru/general/ip-masking
- Передача конфиденциальных данных: https://yandex.ru/support/metrica/ru/general/confidential-data

## OAuth VK ID и Яндекс ID

Целевая модель — получать от провайдера только идентификатор, необходимый для связывания внешнего аккаунта с внутренним аккаунтом YUME. Имя, email, телефон, аватар и другие поля профиля не нужны, если владелец отдельно не утвердит иную функцию.

Требуется проверить scopes в настройках провайдеров и фактические запросы. Код регистрации также запрашивал полную дату рождения у пользователя непосредственно в YUME; это поле не следует путать с данными, предоставляемыми OAuth-провайдером. Необходимость и срок хранения даты рождения пока требуют решения.

Яндекс OAuth: https://yandex.ru/dev/id/doc/ru/  
Инструкция по верификации для сервиса, чей владелец не является гражданином РФ: https://yandex.ru/dev/id/doc/ru/confirm-account

## Хранение пользовательских данных и удаление

Владелец хочет, чтобы удаление аккаунта удаляло всю относящуюся к нему информацию. Перед запуском нужен проверенный процесс, охватывающий как минимум:
- запись аккаунта и никнейм;
- стабильный ID провайдера и связь OAuth;
- историю просмотра и избранное, когда эти функции будут серверными;
- активные сессии, токены/хеши и кэш, относящиеся к аккаунту.

Необходимо отдельно определить поведение логов и резервных копий, их сроки хранения и ротации. Нельзя обещать немедленное удаление из backups, если они не поддерживают точечное стирание. Если в резервных копиях какое-то время остаётся копия записи, это должно быть отражено в процессе и документации в пределах применимых требований.

## Сторонние сервисы в стартовой конфигурации

- Shikimori — источник метаданных каталога; запросы в текущей схеме выполняются с сервера.
- YouTube — источник встроенных трейлеров; браузер может устанавливать соединения с инфраструктурой YouTube.
- VK ID и Яндекс ID — целевые поставщики авторизации, запуск требует проверки.
- Яндекс Метрика — целевая аналитика после согласия; сейчас в коде не обнаружена.
- Selectel — целевой хостинг в РФ; конкретная услуга/БД/backup пока не выбраны.
- Cloudflare — текущая серверная инфраструктура; нужно решить, останется ли proxy/CDN/WAF после миграции и описать реальные потоки.
- Kodik — только будущий кандидат для плеера после разрешения и интеграции.
- Рекламный поставщик — не выбран; реклама отложена.

## Проверки перед запуском

- [ ] С чистым браузером открыть сайт до выбора и убедиться, что Метрика не загружается.
- [ ] Нажать «Отклоняю» и убедиться в отсутствии счетчика и необязательных аналитических запросов.
- [ ] Нажать «Принимаю» и убедиться, что стартует только утверждённая конфигурация.
- [ ] Изменить выбор через настройки и повторно проверить сетевые запросы.
- [ ] Проверить cookies, localStorage, sessionStorage, сетевые домены и поля запросов.
- [ ] Проверить, что OAuth не передаёт лишние поля провайдера.
- [ ] Проверить удаление аккаунта и всех связанных активных записей.
- [ ] Проверить прямой URL возрастного контента и поведение для несовершеннолетних/незалогиненных пользователей.

## Выводы аудита

1. Текущая архитектура использует Cloudflare Workers/Nitro и D1. Переезд на Selectel в РФ — целевой план, требующий миграции runtime, БД и конфигурации, а не простого переноса файлов.
2. Сейчас доступны каталог/метаданные и встроенные YouTube-трейлеры. Полноценного плеера серий нет.
3. Код OAuth VK ID/Яндекс ID существует, но кнопки интерфейса отключены; нужны ключи, callback URI, миграция D1/runtime и end-to-end-проверки. Дополнительно проверить переход VK ID endpoints с id.vk.com на vk.ru, указанный в релизе официального SDK v2.6.1.
4. Яндекс Метрика не обнаружена в проверенном коде; до публикации политики её подключение и настройки надо проверить.
5. Текущий cookie-баннер имеет одну кнопку «Хорошо» и только сохраняет факт закрытия. Выбор принятия/отклонения и блокировка аналитики ещё не реализованы.
6. Геофильтр использует country metadata Cloudflare; при прямом размещении на Selectel его нужно адаптировать.

Публичные документы должны соответствовать фактическому production-поведению. Юридические выводы предварительные; неизвестные сведения перечислены в launch/decisions-needed.md.

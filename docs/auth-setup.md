# YUME: настройка авторизации VK ID и Яндекс ID

**Состояние кода:** backend OAuth и регистрация существуют, но production-авторизация не подтверждена. Кнопки провайдеров в src/components/yume/AuthPage.tsx сейчас имеют disabled. Одна только смена хостинга не активирует вход.

## Текущая реализация

- Роуты: /api/auth/$provider, /api/auth/$provider/callback, /api/auth/register, /api/auth/status.
- Провайдеры: vk и yandex.
- Запрашиваемые scope: VK ID — vkid.personal_info; Яндекс ID — login:info.
- Сервер обменивает OAuth code на токен и запрашивает идентификатор провайдера.
- При регистрации требуется дата рождения и отметка согласия. Сервер сохраняет внутренний ID, провайдера, стабильный ID пользователя провайдера, дату рождения, время и версию согласия.
- Таблица сессий хранит хеш токена и срок окончания. Срок session cookie в коде — 30 дней; OAuth state и временное подтверждение имеют срок около 10 минут.
- Пользовательский UI удаления аккаунта не подтверждён.
- Реализация привязана к Cloudflare Workers и D1; для прямого размещения на Selectel потребуется адаптация runtime и БД.

## Важная проверка актуальности VK ID

В проверенном коде используются конечные точки `https://id.vk.com/oauth2/auth` и `https://id.vk.com/oauth2/user_info`. В официальном журнале релизов VKCOM/vkid-web-sdk для версии 2.6.1 от 12 сентября 2026 г. опубликовано сообщение о переходе авторизации и API-интеграций на домен `vk.ru`. Это потенциально важное расхождение с текущим backend-кодом. Перед запуском нужно сверить актуальные официальные инструкции VK ID и протестировать endpoints / redirect URI; не считать этот провайдер готовым только после размещения на Selectel.

Источник: https://github.com/VKCOM/vkid-web-sdk/releases

## Обязательные значения в текущем Cloudflare-варианте

- YUME_AUTH_SESSION_SECRET — случайный секрет не короче 32 символов.
- YUME_PUBLIC_ORIGIN — публичный HTTPS origin.
- VKID_CLIENT_ID и VKID_REDIRECT_URI.
- YANDEX_CLIENT_ID, YANDEX_CLIENT_SECRET и YANDEX_REDIRECT_URI.

Секреты нельзя коммитить в Git или присылать в чат. Размещайте их в безопасном хранилище секретов целевой инфраструктуры.

## До целевого запуска на Selectel

1. Выбрать услугу Selectel и целевую БД; адаптировать Cloudflare Workers/D1-зависимости.
2. Создать/проверить приложения у провайдеров, разрешения, домен и production callback URI. Для VK ID отдельно перепроверить переход на vk.ru и актуальные OAuth endpoints.
3. Перенести секреты безопасным способом.
4. Включить кнопки UI только после end-to-end проверки.
5. Проверить регистрацию, вход, отказ/отмену, истечение state, создание/истечение сессии, повторный вход и удаление аккаунта.
6. Пересмотреть форму согласия: самостоятельный текст и действие должны быть отделены от Политики и Пользовательского соглашения.
7. Сверить Политику с реальными полями и настройками провайдеров.
